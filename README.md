# Oziris

**Hub for every developer** — a control panel for your Claude Code agents. Run several agents
at once, decide where they work and what they may do, approve risky actions, and connect game
editors such as Roblox Studio through MCP.

**Panel do Twoich agentów Claude Code** — kilku agentów naraz, polityki określające, gdzie
pracują i na co im wolno, zatwierdzanie ryzykownych akcji oraz połączenie z edytorami gier
(np. Roblox Studio) przez MCP.

## Download / Pobieranie

**[Latest release / Najnowsza wersja →](https://github.com/Crisples/oziris-releases/releases/latest)**

| System | File / Plik |
|---|---|
| Windows 10/11 (x64) | `Oziris-Setup-<version>.exe` |
| macOS | `Oziris-<version>.dmg` |

The installers are not code-signed yet: Windows shows “Windows protected your PC” →
**More info → Run anyway**; macOS: right-click the app → **Open**.
The app updates itself (Windows).

Instalatory nie są jeszcze podpisane: Windows pokaże „System Windows ochronił ten komputer” →
**Więcej informacji → Uruchom mimo to**; macOS: prawy klik na aplikacji → **Otwórz**.
Aplikacja aktualizuje się sama (Windows).

## Requirements / Wymagania

- **Claude Code**, signed in with your own Claude subscription (Pro/Max/Team) —
  <https://code.claude.com/docs/en/setup>.
  Oziris runs your own Claude Code; it never sees your Claude credentials and uses no API keys.
- **Git** (on Windows: Git for Windows).
